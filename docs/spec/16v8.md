## Device summary

- 20-pin device: pins 2–9 inputs, pin 1 input or clock, pin 11 input or /OE, pins 12–19 output cells (OLMCs), pin 10 GND, pin 20 VCC. [G2]
- AND array of 64 product terms × 32 input lines = 2,048 fuses. Each OLMC owns 8 product terms (a 256-fuse block); the 8th can serve as the output-enable term. [D1]
- Operating modes, set by SYN, AC0 and each OLMC's AC1 (XOR sets polarity: 0 = active low, 1 = active high): [D1][G2]

| Mode | SYN | AC0 | AC1(n) = 0 | AC1(n) = 1 |
| --- | --- | --- | --- | --- |
| Simple | 1 | 0 | combinational output | dedicated input |
| Complex | 1 | 1 | — | combinational I/O (tristate) |
| Registered | 0 | 1 | registered output | combinational I/O |

- Endurance 100 erase/write cycles, data retention 20 years, erase time under 100 ms. [D1]

## Row map

Rows are selected with RA0–RA5 (row 0–63). [G1]

| Row | Width | Contents | Source |
| --- | --- | --- | --- |
| 0–31 | 64 bits | AND-array fuses | [G1] |
| 32 | 64 bits | User Electronic Signature | [G1] |
| 33–59 | 64 bits | reserved | [G1] |
| 60 | 82 bits | Architecture Control Word (ACW) | [G1] |
| 61 | — | security bit | [G1] |
| 62 | — | reserved | [G1] |
| 63 | — | bulk erase | [G1] |

**ACW bit order (row 60), GAL16V8A/B:** bits 0–3 XOR, bit 4 AC0, bits 5–8 AC1, bits 9–72 PT0–PT63 (product-term enables), bits 73–76 AC1, bit 77 SYN, bits 78–81 XOR. The original GAL16V8 (no suffix) uses a different order. [G1]

## Sequences

**Read a row:** set P/V low; put the row address on RA0–RA5; pulse /STR low to load the row into the device's shift register; then give one rising edge on SCLK per bit, reading SDOUT for each. [G1]

**Write a row:** set P/V high; put the row address on RA0–RA5; shift the row's bits in on SDIN, one rising SCLK edge per bit; pulse /STR low for the programming pulse width (table below). [G1]

**Bulk erase:** set P/V high, select row 63, pulse /STR low for 100 ms, then set P/V low. [G1]

**Programming flow (J48):**
1. With the socket unpowered, select the 20-pin configuration: Q1 (ZIF 10 GND) and Q6 (ZIF 28 VCC). See the Rev H switch table.
2. Apply VCC, hold all non-programming pins low, then raise EDIT to the read level.
3. Identify the device and its algorithm (see Open questions), then bulk erase at the programming level.
4. Write rows 0–31, the UES (row 32) and the ACW (row 60) at the programming level and pulse width.
5. Drop to the read level and read every row back to verify.
6. If the JEDEC file has `G1`, set the security bit (row 61).
7. Lower EDIT to 0 V before removing VCC.

## Atmel ATF16V8B differences

- The ATF electronic signature does not encode programming parameters; it holds the part number as byte-reversed text (for example "1F16V8B1" for an ATF16V8B). Interpreting it as a GAL signature selects the wrong algorithm. [A1]
- Atmel parts should be conditioned before programming: program all cells to 0 twice, then erase. Verify errors during conditioning can be ignored. [A1]
- ATF parts have input pull-ups or pin keepers; most Lattice GAL16V8/16V8B parts do not. [A1]
- Programming voltage requirement for ATF parts: see Open questions.

## Open questions

Each needs a published source before firmware depends on it.

- [ ] **Signature row and algorithm code:** which row holds the programmer electronic signature (PES), its width, and how its bytes encode manufacturer, algorithm, EDIT voltage and pulse width.
- [ ] **Row-to-fuse mapping:** how programming rows 0–31 (64 bits each) map onto the JEDEC array (64 product terms × 32 inputs), including whether the input-line order is linear.
- [ ] **Bit order:** which bit is shifted first when writing and reading a row, and how ACW bits map onto JEDEC fuses 2048–2193.
- [ ] **Original GAL16V8 ACW order** (no-suffix parts), which [G1] says differs from the A/B order.
- [ ] **Security bit (row 61):** the exact write sequence.
- [ ] **Timing:** SCLK high/low times, setup and hold of SDIN and RA lines, settling time after changing EDIT level, delay after /STR before reading.
- [ ] **ATF16V8B:** its programming EDIT voltage, pulse widths and erase sequence.
- [ ] **JEDEC checksum detail:** see [jedec.md](jedec.md).
